## 二、00_index.md（叙事式序章）

### 语句通顺

1. **[中] "完成不是模型说'完成了'"节** —— 原文："这也改变了评估 Coding Agent 的问题方式。"
   "问题方式"不是通顺的现代汉语搭配，读者需回读才能确认意思是"应该提什么问题"。
   建议改为："这也改变了评估 Coding Agent 时应该提出的问题。"

2. **[低] 同节** —— 原文："为了在不同实现之间保持同一套问题，统一参考架构把……"
   "保持同一套问题"动宾搭配生硬。建议："为了在谈论不同实现时仍指向同一套问题，……"

3. **[低] 全文** —— 自我指称不统一：第 55 行"本报告"、第 57 行"全书"、第 59 行"报告"
   混用；`WRITING_PLAN.md` 通篇使用"报告"。建议全书统一为"本报告"。

### 描述清楚

4. **[中] "用三种视角理解七个 Harness"节·读者路线** —— 初学者路线写为"从本序章顺序阅读
   '认识 Agent Harness'、横向地图、纵向生命周期和参考架构"（即 01→02→03→04），而
   `WRITING_PLAN.md` 5.5 节的初学者路线是 `00 → 01 → 03 → 04 → 05…`，明确跳过 `02`
   （`02` 被定位为"适合已有 agent 基础、希望快速查询特定机制的读者"）。二者应统一：
   要么修订序章路线，要么修订 5.5 节并说明理由。另外平台开发者路线在序章中包含了
   `02`、`03`，而 5.5 节为 `01 → 04 → 05–22…`，同样存在小幅出入（低）。

5. **[中] "当前第一部分，以及接下来会去哪里"节** —— "第一部分"这一划分在全书中从未被
   定义：读者不知道全书共几个部分、各部分边界在哪里；同节下文又说"后续内容将分为几组"，
   "部分"与"组"两个层级词混用。建议在首次出现处用一句话交代全书的分部结构（哪怕只是
   "本报告分为序章与总览、核心机制、个案、综合与附录等部分"），并统一"部分/组"的用法。

6. **[低] 同节** —— 原文："本序章先回答……；第一章给出……；第四章则把时间线与能力图
   翻译成结构。四章合在一起构成后续阅读的共同语言"——前文列举了序章加第一至第四章共五个
   单元，"四章合在一起"易被误读为包含序章。建议明确为"第一至第四章合在一起"或
   "序章与这四章合在一起"。

7. **[低] "用三种视角理解七个 Harness"节** —— 横向视角句带 `02` 链接、参考架构句带
   `04` 链接，唯独纵向视角句没有链接到 `03`，同一段内链接节奏不一致。建议补上
   `[纵向生命周期](03_vertical_lifecycle_walkthrough.md)`。

## 七、跨章节问题

1. **[中] 00 与 03 的近重复表述** —— `00`"一个建议怎样变成现实中的行动"节："权限判断
   表达'这次行动是否获准'，沙箱、容器或操作系统限制则决定'行动即使获准，最多能够影响
   什么'；两者不能互相替代。"与 `03`"从行动提议到真实副作用"节："确认框回答的是'用户
   是否同意这次动作'，沙箱回答的是'即使动作获准，它最多能影响什么'；两者解决的问题
   不同。"两句几乎同构，`04`"总体结构"节又第三次复述同一区分。`IMPLEMENTATION_PLAN.md`
   明确要求"00 引出问题，03 形式化生命周期，04 定义参考架构，三章不重复成段内容"。
   建议：`00` 保留直觉版，把"两者不能互相替代"的明确论断留给 `03`，`04` 只引用结论。

2. **[中] diff／测试／说明"三产物"三分法重复三次** —— `00`"完成不是模型说'完成了'"
   节（"diff 回答'改了什么'……三者彼此补充，不能相互冒充"）、`03`"从行动提议到真实
   副作用"节（"三种不同产物：diff 说明改了什么……任何一种都不能单独替代另外两种"）、
   `04`"信任边界"节（"diff 显示工作树差异……最终解释把原因、改动和限制交给人类"）
   三次展开同一组对比。与之类似，"摘要把'测试曾失败'写成'测试已处理'"的例子在 `00`
   （"当任务装不下"节）和 `04`（"本轮上下文、可检索记忆与压缩"节）重复出现。单次回顾
   可以强化记忆，三次同例则显得冗余。建议：`00` 只抛现象，完整三分法留在 `03`，`04`
   以 Artifact 定义的形式一句话回收；"测试已处理"的例子二选一保留。

3. **[低] 00 与 01 的开场白同构** —— 两章均以"设想……配置解析错误……运行相关测试，
